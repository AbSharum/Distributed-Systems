# Distributed Systems Coursework

Problem sets and in-class exercises from a Distributed Systems / Operating Systems fundamentals course.

## Contents

- `PS1/` — Array sum and related Java exercises.
- `inclass-10-1-2025/` — In-class file-processing exercise.
- `Distributed/` — Reference reading material (lecture PDFs on processes, scheduling, locks, concurrency).

## Stack

Java.

## Running

Each folder is self-contained. Compile/run the `.java` files directly, or use the included `run.sh`/build scripts where present.
